# Sistema de interactivo
Este proyecto en JavaScript solicita al usuario su nombre y edad mediante prompt().
Luego valida si la edad ingresada es correcta y determina si la persona es mayor o menor de edad.

## Tecnologías utilizadas

- JavaScript

## Funcionamiento
-El programa solicita el nombre del usuario.
-Luego pide la edad.
-Se valida si la edad es un número válido.
Si la edad es menor a 18:
-Muestra que el usuario no es mayor de edad.
Si la edad es 18 o mayor:
Indica que el usuario es mayor de edad.
